# Reference material — Duane Blehm's *StuntCopter* (public domain)

This directory holds the **original 1986 Macintosh game** by **Duane Blehm** —
the Pascal source (`StuntCopter.pas`), RMaker script (`.R`), FullPaint shapes
(`.shapes`), and the resource fork (`.appledouble`) — kept **verbatim** as the
source of truth the modern port is derived from. `../scripts/` decode and slice
these into the sprite atlas and other assets.

**Provenance and rights.** *StuntCopter* was written by Duane Blehm, who died in
the 1980s. His family subsequently released his games into the **public domain**.
These files are included here unmodified, for preservation, attribution, and
faithful derivation.
