# OpenSC — StuntCopter

A faithful, multiplatform Rust/[macroquad] port of Duane Blehm's 1986 Macintosh
game *StuntCopter*: fly the helicopter, drop the stuntman, and land him in the
moving hay wagon far below.

Runs natively on Windows, macOS, and Linux, and in the browser via WebAssembly.

## Controls

- **Mouse** — position steers the copter (centre is a hover dead zone); **click** drops.
- **Arrow keys / WASD** — steer; **Space** drops.
- **Touch** — drag to steer, tap to drop.

## Status

Pre-release. Currently a walking skeleton: the copter flies (with inertia) over a
rolling wagon, rendered through an integer-scaled virtual canvas that stays crisp
from 4K to a phone. The stuntman, collisions, scoring, sound, and high-score
persistence are in progress. See `AGENTS.md` for conventions and scope.

## Build & run

Native:

```sh
cargo run
```

Web — builds a self-contained static `dist/` (serve over http, not `file://`):

```sh
npm run build:web
npx serve dist   # then open the printed URL
```

Or with Docker:

```sh
docker build -t opensc .
docker run --rm -p 8080:80 opensc   # http://localhost:8080
```

## Layout

- `src/` — the game, one focused module per concern (see the module docs)
- `assets/atlas.png` + `src/atlas.rs` — sprite atlas, generated by `scripts/gen_atlas.py`
- `reference/` — the original Pascal source and decoded art (the port's source of truth)
- `web/` — the WebAssembly page shell and the vendored macroquad loader
