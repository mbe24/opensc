# OpenSC — StuntCopter

A faithful, multiplatform Rust/[macroquad] port of Duane Blehm's 1986 Macintosh
game *StuntCopter*: fly the helicopter, drop the stuntman, and land him in the
moving hay wagon far below.

Runs natively on Windows, macOS, and Linux, and in the browser via WebAssembly.

## Controls

- **Mouse** — position steers the copter (centre is a hover dead zone); **click** drops.
- **Arrow keys / WASD** — steer; **Space** drops.
- **Touch** — drag to steer, tap to drop.

## Status

Playable. The full loop is in: fly (with inertia) over the rolling wagon, drop
the stuntman, and land him — with the success backflip, the splat/driver/horse
crashes, level progression with rising difficulty, the attract / paused /
game-over scenes, and procedurally synthesized sound. Everything renders through
an integer-scaled virtual canvas that stays crisp from 4K to a phone. High score
is session-only for now (persistence is deferred). See `AGENTS.md` for
conventions and scope.

## Build & run

Native:

```sh
cargo run
```

Web — builds a self-contained static `dist/` (serve over http, not `file://`):

```sh
npm run build:web
npx serve dist   # then open the printed URL
```

Or with Docker:

```sh
docker build -t opensc .
docker run --rm -p 8080:80 opensc   # http://localhost:8080
```

## Layout

- `sim/` — the platform-agnostic game simulation (state, rules, tick); **no macroquad**
- `src/` — the macroquad presentation layer (rendering, input, audio, scenes)
- `assets/atlas.png` + `sim/src/sprite.rs` — sprite atlas, generated by `scripts/gen_atlas.py`
- `reference/` — Duane Blehm's original Pascal source and decoded art (public domain; see below)
- `web/` — the WebAssembly page shell and the vendored macroquad loader

## Credits & attribution

*StuntCopter* was created by **Duane Blehm** (1986–1987). After his death, his
family released his games into the **public domain**. This project is a
from-source port for preservation and learning; `reference/` holds his original
Pascal source and Mac resources, kept verbatim as the port's source of truth,
and `assets/*.png` are derived from them via `scripts/`.
